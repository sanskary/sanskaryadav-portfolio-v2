# 03 — DESIGN SYSTEM

## Direction
**Editorial strategy portfolio × modern digital product quality.**

The visual language should communicate intelligence and professionalism before technology.

## Layout
- Strong typographic hierarchy
- Generous whitespace
- Editorial rhythm
- Asymmetric but controlled grids
- Large project imagery
- Restrained borders and cards
- Responsive-first design
- No template-like section repetition

## Typography
Use a highly legible modern sans-serif for interface/body text and a distinctive editorial display treatment for major headings. Prioritise hierarchy, readability and restrained personality over novelty.

## Colour
Base: warm/off-white or very light neutral background.
Text: deep charcoal/near-black.
Accent: one restrained signature colour.
Supporting neutrals should do most of the visual work.

Avoid:
- Rainbow gradients
- Excessive cyan/purple "AI" glow
- Black neon dashboards
- Overuse of glassmorphism

## Components
- Minimal navigation
- Editorial project cards
- Large image-led case-study headers
- Compact metadata labels
- Clear text links
- Strong but restrained CTA buttons
- Data/metric callouts only when verified

## Intelligent animation
Animation should communicate hierarchy, continuity and interaction—not decoration.

Use:
1. Subtle page-load text reveal.
2. Project image movement on hover.
3. Smooth card expansion/transition into case studies.
4. Scroll-based section reveals with restrained distance.
5. Number/metric animation only for verified metrics.
6. Shared-element style transitions where technically appropriate.
7. Navigation state transitions.
8. Reduced-motion fallback.

Avoid:
- Constant floating elements
- Random parallax
- Cursor-following gimmicks
- Excessive bounce
- Animation on every component
- Long loading sequences

## Accessibility
- Respect prefers-reduced-motion.
- Maintain strong contrast.
- Never make content dependent on animation.
- Keep touch targets usable on mobile.

## Visual hierarchy
The six projects should not receive identical visual treatment. One or two can be featured prominently; the remainder should form a coherent work archive.

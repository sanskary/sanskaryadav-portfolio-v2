# 04 — BUILD SPEC

## Goal
Build a premium personal portfolio for Sanskar Yadav that feels professionally art-directed and communicates strategy, research and real-world systems—not a generic AI-generated developer portfolio.

## Pages

### Home
1. Navigation
2. Hero positioning
3. Short credibility/context statement
4. Selected work
5. Capability/approach
6. About snapshot
7. Contact CTA
8. Footer

### Work
- All six projects
- Category/filtering only if it genuinely improves navigation
- Strong project cards
- Clear project metadata

### Case study
Reusable structure:
1. Hero
2. Project overview
3. Context
4. Problem
5. My role
6. Research/discovery
7. Approach
8. Solution
9. Technology/method
10. Evidence/outcomes
11. Limitations/confidentiality where relevant
12. Related work
13. Next project

### About
- Personal positioning
- Economics background
- Interdisciplinary practice
- Political communication/digital strategy
- Relevant capabilities
- Contact

### Contact
- work@sanskaryadav.in
- Clear professional CTA
- No unnecessary contact form complexity unless useful

## Content rules
- Source all project claims from `02_PROJECTS.md`.
- Never invent metrics, clients, technologies or outcomes.
- Keep confidential information out of public pages.
- Electoral AI language must distinguish candidate anomalies from proven wrongdoing.
- Use authentic project visuals wherever possible.

## Technical direction
- Component-based architecture.
- Semantic HTML.
- Responsive layouts.
- Optimised images.
- Fast initial render.
- Accessible keyboard navigation.
- Reduced-motion support.
- Clean URL structure.
- SEO metadata per page/case study.
- Open Graph metadata.
- 404 page.
- Analytics only if intentionally added.

## Interaction quality
Motion should reinforce the editorial structure:
- Enter/exit transitions between project pages.
- Image reveal/mask transitions.
- Subtle hover states.
- Scroll-triggered reveals.
- No gratuitous animation.

## Quality gate
Before launch verify:
- Mobile at common widths
- Tablet
- Desktop
- Keyboard navigation
- Reduced motion
- Performance
- Broken links
- Image compression
- Metadata
- Favicon
- Contact link
- No placeholder text
- No unsupported claims

## Source of truth
`01_PROJECT_BRIEF.md` = brand and narrative  
`02_PROJECTS.md` = project truth  
`03_DESIGN_SYSTEM.md` = visual/interaction language  
`04_BUILD_SPEC.md` = implementation instructions
